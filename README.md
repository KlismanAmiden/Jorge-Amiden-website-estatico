# Jorge Amiden — Website

Website estático desenvolvido como uma homenagem e espaço de apresentação da trajetória musical de **Jorge Amiden**.

O projeto reúne informações sobre sua carreira, trabalhos musicais e sua contribuição para a música brasileira.

## 🎵 Sobre o projeto

Este site foi desenvolvido com o objetivo de apresentar, de forma simples e visual, informações sobre Jorge Amiden e sua trajetória artística.

O projeto foi desenvolvido utilizando apenas tecnologias web fundamentais, sem a utilização de frameworks.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## 📁 Estrutura do projeto

```text
Site_JA/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💻 Como executar

Por ser um site estático, não é necessário instalar dependências.

Basta clonar o repositório:

```bash
git clone https://github.com/KlismanAmiden/Jorge-Amiden-website-estatico.git
```

Depois, abra o arquivo `index.html` em um navegador.
